Currently

I'm consolidating seven years of front-end work into a senior FE-focused resumé, and rebuilding this site around a design system derived from JetBrains' Cyan Light theme. The palette is doing the heavy lifting: every color on this page has a name and a job.

This is a work in progress. The navigation, typography, and token layer are the ideas I'm trying on — push back if anything feels wrong.

Colophon

Body text is set in Georgia; UI chrome in system-ui. Code samples use the same token names as my Helix editor — syntax-keyword, syntax-string, and friends — so everything from the IDE to the website speaks the same dialect.
