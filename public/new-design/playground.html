Playground

A sandbox of small things. · Updated irregularly.

Most of these started as a question I couldn't answer by reading. Some are half-finished; a few are idle loops I like to leave running. Click any card to open the live toy.

Nothing here is production-grade. They exist to learn a technique, test a hypothesis, or keep my hands busy between deploys.

Canvas & graphics

Fractal tree

A recursive tree drawn to canvas with parameterized angle, length decay, and colour roll. The thing currently idling on the home page.

canvas recursion TypeScript
Voronoi mouse field

Voronoi cells that re-tessellate toward the cursor — a study in how spatial partitioning feels when it's reactive instead of static.

canvas geometry
Palette weaver

Drop two hex values and watch the tool interpolate through OKLCH, LAB, and HSL — a side-by-side you can stare at until one colour space wins you over.

colour OKLCH

Typography

Modular scale explorer

A knob-driven playground for picking type scales — ratios, base sizes, breakpoints — with live previews of body, headings, and small text.

type CSS
Variable font keyboard

Map arrow keys and modifiers to a variable font's axes. Mostly useful for convincing yourself a weight axis isn't the same as a grade axis.

type variable fonts

Motion

Easing comparator

Run two easing curves side by side on the same path. Useful when you can't decide between ease-in-out and a cubic-bezier you just made up.

motion SVG
Spring physics lab

Tweak stiffness, damping, and mass on a draggable blob. Once you've felt a spring you stop using durations.

motion physics

Sketch-pad

Things I'm still chewing on, not yet ready to open in a browser:

  • A tiny visualiser that shows which cascade layer each rule on the page came from.
  • A WebGL shader scratchpad with the editor's syntax palette mirrored into the output.
  • A view-transition explorer that lets you record a UI flow and export the minimum CSS to make it feel like native.
